# my.example: образец личной папки

Установщик (`tools/install.py`) копирует эти файлы в папку `my/` рядом, если их там ещё нет.
В `my/` живёт всё личное: настройки, ключи, карта Telegram-чатов, резервные копии старых версий.
`my/` в git не попадает никогда (см. `.gitignore`), поэтому обновление пакета (`git pull`) её не трогает,
а на GitHub уходит только этот образец.

| Файл | Что это |
|---|---|
| `my-config.md` | язык, город, лимиты трат, предпочтения |
| `keys-template.txt` | образец файла ключей (в `my/` он лежит под именем файла ключей, который читают скрипты) |
| `telegram-chats.md` | карта своих Telegram-чатов (по желанию) |
| `private-words.txt` | личные слова, которые нельзя отправлять на GitHub |

Где лежит `my/` у вас: `python -I skills/social-capture/scripts/keys.py where`.
