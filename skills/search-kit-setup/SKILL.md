# Знакомство, установка и обновление search-kit

Ведёшь человека как новичка, который видит пакет впервые: по шагам, простыми словами, на его языке. На каждом шаге:
что делаем, зачем, сколько стоит; сначала проверка, что уже есть, и только недостающее. Ничего не ставишь и не
меняешь без «да». Ключи человек вписывает сам: ты их не видишь, не просишь прислать в чат и не выводишь. Прислал ключ
в чат: не ругать, помочь перенести в файл ключей и предложить выпустить новый ключ в кабинете сервиса.

**Как говорить.** Человек не программист. Технические подробности (пробный прогон, junction, kit-home.txt, имена
файлов и команд, пути к служебным папкам) держи при себе; человеку — что изменится для него и зачем, в 2–4 строках.
Подробности — только если спросит. Одно сообщение — один шаг и один вопрос в конце.

**Первое сообщение — всегда знакомство (шаг 0), до любых проверок и установки.** Даже если пакет уже скачан и всё
проверено: сначала знакомство и «Начинаем?», потом остальное.

`{пакет}`: папка пакета (копия репозитория). `{скилы}`: `{пакет}/skills`. В BB и в плагине Claude Code скилы
работают из копии в служебной папке оболочки: тогда путь к пакету печатает
`python -I "<папка этого скила>/../social-capture/scripts/keys.py" where` (строка «Папка личных данных» = `{пакет}/my`).
Команды: `python -I "<полный путь>"` (на Mac и Linux `python3`), прямые косые, путь в кавычках.

## Шаг 0. Знакомство (первое сообщение, своими словами, но всё из этого списка)
Коротко и просто, как другу. Пример:

«Привет! Я search-kit. Я помогаю вашему агенту искать в интернете.

Вы просто спрашиваете своими словами, например:
- «какой телефон до $500 лучше снимает ночью: что пишут владельцы» — соберу отзывы людей с Reddit и YouTube и сравню;
- «отель в Стамбуле у моря до $100 за ночь, чтобы в свежих отзывах хвалили чистоту» — посмотрю карты, отзывы и цены;
- «стоит ли читать «Дюну», о чём она и что о ней думают читатели» — найду разборы и мнения;
- «сколько сейчас стоит ChatGPT Plus и что в него входит» — возьму живую цену с сайта, а не по памяти.
Я сам решаю, где искать, читаю найденное и приношу ответ со ссылками. В конце пишу, сколько это стоило.
Примеры — именно эти, общие и понятные всем; не подстраивать под работу человека.

Где ищу: Google, YouTube, Reddit, X, Threads, Instagram, TikTok, карты с отзывами, магазины и отели, GitHub,
научные статьи. По желанию ещё ваши Telegram-чаты. Ещё умею разобрать пост по ссылке и сделать большое
исследование.

Чтобы я заработал, нужно 6 сервисов, у всех есть бесплатный тариф:
- Keenable: быстрый поиск по интернету (основа поиска вместе с Google);
- ScrapeCreators: Google, YouTube, Reddit, Threads, Instagram, TikTok;
- Apify: X и карты с отзывами;
- Tavily: читает страницы сайтов целиком;
- Firecrawl: живые цены и цифры, сайты с защитой;
- Groq: расшифровка речи из видео.
Я подскажу, где зарегистрироваться и как подключить каждый.

Займёт минут 15. Начинаем?»

Список сервисов называть полностью, все 6, без пометок «по желанию»: все обязательны.

## Шаг 1. Где мы
- Оболочка: есть переменная окружения `BB_THREAD_ID` → BB; это Claude Code (приложение Claude или `claude`
  в терминале) → Claude Code; иначе спросить (Codex, Gemini CLI, OpenCode и т. п.).
- Система: Windows, Mac или Linux.
Сказать человеку, что определил.

## Шаг 2. Программы
Проверить: `python --version` (нужен 3.10+; на Mac и Linux `python3 --version`), `git --version`, по желанию
`ffmpeg -version` (только для кадров из видео). Нет чего-то: предложить установку (с вопросом). Windows:
`winget install Python.Python.3.13`, `winget install Git.Git`, `winget install Gyan.FFmpeg`; Mac:
`brew install python git ffmpeg`; Linux: пакетный менеджер (`sudo apt install python3 git ffmpeg`). Windows: после
`winget` закрыть и заново открыть терминал (или начать новую сессию агента). `python` открывает Microsoft Store:
это заглушка Windows; поставить Python через `winget` и отключить заглушку: Параметры → Приложения → Псевдонимы
выполнения приложений → выключить python.exe и python3.exe.

## Шаг 3. Папка пакета и установка в оболочку
Пакет уже склонирован (этот скил запущен из него или из копии с `kit-home.txt`): шаг 3а пропустить.
- **3а. Скачать.** Спросить, где держать папку пакета: там, где у человека всё для агентов (у кого есть рабочая папка,
  туда; иначе домашняя папка). `git clone <ссылка на репозиторий, которую дал человек> "<папка>/search-kit"`.
  Нет git: скачать архив (Code → Download ZIP) и распаковать (тогда обновление вручную).
- **3б. Поставить.** Сначала пробный прогон (`--dry-run`, для себя). Человеку сказать простыми словами, без путей и
  технических слов: «Поставлю навыки так, чтобы их видели все ваши агенты, и создам папку для ваших настроек и
  ключей. Ничего ваше не трогаю, убрать можно в любой момент. Ставлю?» После «да» без `--dry-run`:
  - BB: `python -I "{пакет}/tools/install.py" bb --dry-run`
  - Claude Code: `python -I "{пакет}/tools/install.py" claude --dry-run`
  - другая оболочка: `python -I "{пакет}/tools/install.py" "<её папка скилов>" --dry-run` (Codex: `~/.codex/skills`;
    не знаешь: спросить или посмотреть в документации оболочки).
  Установщик создаёт `my/` из образца, кладёт адрес пакета в каждый скил и ставит скилы ярлыками (в Claude Code:
  плагином). Чужие скилы не трогает; старые копии своих убирает в `my/backups/`.
- **3в. Проверить:** скилы видны без дублей (BB: `bb skill list`; Claude Code: `claude plugin list`). Дубль (такой же
  скил ещё в `~/.claude/skills` или другой папке): сказать и предложить убрать старую копию в резервную папку (после «да»).
  В текущей сессии новые скилы могут быть не видны: дальше идти по этому файлу, он уже прочитан.

## Шаг 4. Ключи
Перед регистрацией рассказать по каждому сервису: зачем он, что бесплатно и как получить больше. Проверено
26.11.2026 по страницам сервисов; цифры меняются, перед рассказом свериться со страницей цен (быстрый поиск
или `firecrawl_scrape` с `maxAge: 0`):
| Сервис | Где | Бесплатно | Как получить больше |
|---|---|---|---|
| Keenable | keenable.ai | 100 000 запросов в месяц с ключом | регистрироваться на обычную почту: с одноразовой почтой дают только 1 000 |
| ScrapeCreators | scrapecreators.com | 100 кредитов при регистрации, не сгорают | ещё до 1 200 в кабинете: 100 за ответ «откуда узнали», 100 за звезду их репозиторию на GitHub, 1 000 за честный отзыв на G2. Потом пополнение: $47 за 25 000 |
| Apify | apify.com | $5 в месяц, обновляются каждый месяц | хватает на обычный поиск; сверх $5 не списывает, а отказывает |
| Tavily | tavily.com | 1 000 кредитов в месяц | — |
| Firecrawl | firecrawl.dev | 1 000 кредитов в месяц | — |
| Groq | console.groq.com | бесплатно: до 2 000 расшифровок в день, около 8 часов аудио в сутки | — |
Ещё предложить поискать промокоды и бонусы при регистрации (`{скилы}/search-and-read-web/references/promo-codes.md`).
Порядок регистрации: по одному сервису за раз — рассказал, человек зарегистрировался и получил ключ, следующий.
1. Что уже есть: `python -I "{скилы}/social-capture/scripts/keys.py" check`. Ключи в переменных среды и в общем файле
   подхватываются сами: если всё найдено, шаг закончен.
2. Спросить: «Ключи храним в папке пакета (`my/`) или у вас есть общий файл ключей на все сервисы?» Есть общий файл:
   `python -I "{пакет}/tools/install.py" keys-file "<путь к нему>"` (скрипт впишет путь, ключи не читает).
3. Недостающие ключи вписывает человек:
   - BB: форма секретов, агент значений не видит:
     `bb secret request KEENABLE_API_KEY SCRAPECREATORS_API_KEY APIFY_TOKEN TAVILY_API_KEY FIRECRAWL_API_KEY GROQ_API_KEY --write-env "<файл ключей>" --purpose "Ключи для поиска search-kit" --describe "SCRAPECREATORS_API_KEY=Google, YouTube, Reddit, соцсети" --describe "APIFY_TOKEN=X, ответы Threads, карты" --describe "GROQ_API_KEY=расшифровка речи" --describe "KEENABLE_API_KEY=быстрый поиск" --describe "TAVILY_API_KEY=чтение страниц" --describe "FIRECRAWL_API_KEY=живые цифры, защищённые сайты"`.
     `<файл ключей>`: общий файл, если указан, иначе `{пакет}/my/` + файл ключей из строки «Файлы ключей» вывода
     `keys.py where`. Охранник оболочки отклонил команду: дать её человеку, он запустит сам в терминале BB.
   - Остальные: `python -I "{скилы}/social-capture/scripts/keys.py" add-missing keenable tavily firecrawl` допишет пустые строки и напечатает
     путь; человек сам открывает файл (Windows: Win+R, `notepad "<путь>"`; Mac: `open -e "<путь>"`; Linux: любой
     редактор), вставляет ключи после «=», сохраняет. Агент файл не открывает.
   - Неверный ключ заменить: человек сам удаляет строку в редакторе и вписывает заново (форма BB уже вписанную
     строку не перезаписывает).
4. Проверка: `python -I "{скилы}/social-capture/scripts/keys.py" test`.
5. **Закрыть файл ключей от агента.** Ключи читают только скрипты пакета; агент открывать файл не должен, даже если
   его запутала чужая страница. Проверить и, если не закрыт, предложить (с «да», копия настроек до правки):
   - Claude Code с плагином пакета: охранник пакета уже закрывает `keys.env`, `credentials.md` и папку `secrets/`.
   - Claude Code без плагина (в том числе агент Claude Code в BB: у BB охранника пакета нет): добавить в
     `~/.claude/settings.json`, раздел `permissions.deny`, запреты на файл ключей и его папку:
     `Read(//<путь к папке ключей>/**)`, `Bash(*<имя файла ключей>*)`, `PowerShell(*<имя файла ключей>*)`.
     Если у человека свой охранник (хук), предложить добавить туда то же имя файла и папку. После правки проверить:
     попытка прочитать файл отклоняется, а `keys.py test` по-прежнему видит ключи.
   - Codex и другие агенты без хуков: сказать честно, что файл держится только на правилах скилов; ключи с лимитом
     трат в кабинетах сервисов снижают риск.

## Шаг 5. Подключения поиска (обязательно)
Keenable (быстрый поиск, основа вместе с Google), Tavily (чтение страниц целиком), Firecrawl (живые цифры,
защищённые сайты). Все три нужны: без них поиск заметно слабее. Подключения у каждого агента свои: ставятся
для каждого агента, которым человек пользуется. Сначала посмотреть, что уже подключено, и не дублировать.
Ключи этих сервисов — в тот же файл ключей (шаг 4: `KEENABLE_API_KEY`, `TAVILY_API_KEY`, `FIRECRAWL_API_KEY`).
- Claude Code (и агент Claude Code в BB): `references/claude-code.md`, раздел «Подключения поиска».
- Codex, Gemini CLI, Antigravity и другие агенты BB: `references/bb.md`, раздел «Подключения поиска».
- Проверка в новой сессии или треде: по одному пробному вызову каждого.

## Шаг 6. Город и лимит трат (по желанию, один вопрос)
Не анкета. Один вопрос простыми словами, например:
«Хотите, я запомню ваш город? Тогда на вопросы вроде „где поужинать рядом“ буду сразу искать там. И могу
запомнить, сколько тратить без вопроса: сейчас до $0,5 за один дорогой поиск, дороже спрошу. Можно пропустить,
всё и так работает.»
- Ответил: записать в `{пакет}/my/my-config.md` (город, лимит; язык — только если попросил другой) и сказать одной
  строкой, что запомнил.
- Пропустил: ничего не спрашивать дальше. По умолчанию: город не задан (местная тема — город из вопроса), язык как
  в разговоре, лимит $0,5. Поменять можно в любой момент фразой агенту («запомни мой город», «лимит $1»).
Имя, работу, интересы и прочее не спрашивать.

## Шаг 7. Telegram (по желанию)
Спросить, нужен ли. Нет: пропустить.
- **Аккаунт.** Пакет рассчитан на **второй аккаунт Telegram**: агент читает только чаты, куда этот аккаунт вступил,
  личная переписка ему не видна. Нет второго: можно завести или подключить основной на своё усмотрение.
- **Одна сессия — одно устройство.** Агент работает на нескольких устройствах (компьютер, сервер)? На каждом свой
  вход. Одну и ту же строку сессии с двух IP одновременно Telegram сбрасывает (ошибка AuthKeyDuplicated: «used
  under two different IP addresses simultaneously»). Это не бан, но вход придётся делать заново. Поэтому строка
  сессии хранится с именем устройства, и общий файл ключей можно синхронизировать: каждое устройство берёт свою.
- Нужен `uv`: `uv --version`; нет: Windows `winget install astral-sh.uv`, Mac `brew install uv`, Linux
  `curl -LsSf https://astral.sh/uv/install.sh | sh` (с вопросом).
- Сервер: открытый `telegram-mcp` (github.com/chigwell/telegram-mcp): `git clone` рядом с папкой пакета, `uv sync`.
- `{пакет}/my/telegram.json`: `{"repo": "<папка telegram-mcp>"}`.
- Ключи в файл ключей (вписывает человек): `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` с my.telegram.org (общие для
  всех устройств). Вход: человек сам запускает в терминале `python -I "{скилы}/telegram-search/scripts/tg_launch.py" login`
  (QR-код; `login-phone` — по номеру), на вопрос про файл настроек сервера отвечает «n», полученную строку сессии
  вписывает в файл ключей под именем, которое напечатал скрипт (`TELEGRAM_SESSION_STRING_<ИМЯ_КОМПЬЮТЕРА>`).
- **Экономные настройки (предложить).** Режим `read` запускателя скрывает около 40 инструментов, которые для поиска
  не нужны (контакты, админка, стикеры, черновики, реакции и т. п.): их описания не занимают контекст каждой
  сессии, а личные данные не на виду. Режим `join` добавляет вступление в каналы по ссылке. Предложить `read` по
  умолчанию; подключение агенту (если он должен видеть инструменты Telegram напрямую): команда
  `python -I "{скилы}/telegram-search/scripts/tg_launch.py" read` как сервер MCP (stdio). Скрипту поиска
  подключение не нужно: он запускает сервер сам.
- Карту чатов построить по разделу «Карта чатов: как построить» скила `telegram-search` в `{пакет}/my/telegram-chats.md`.
- Проверка: `python -I "{скилы}/telegram-search/scripts/tg_search.py" global <временная папка> --q "<слово>"`.

## Шаг 8. Браузер
Для магазинов, отелей и площадок с фильтрами нужен браузер агента: встроенный браузер оболочки (приложение Claude:
браузерная панель; BB: его браузер). Проверить, что он есть. Запасной: agent-browser (по желанию, отдельный профиль,
входы только в запасные аккаунты); путь к профилю: в `my/my-config.md`.

## Обучалка: как пользоваться
- Спрашивать своими словами: «найди…», «что пишут про…», «какой лучше…», «посмотри в Reddit…». Назвал площадку:
  агент пойдёт туда обязательно.
- Ссылка на пост: «разбери этот пост». Большая тема: «сделай глубокий ресерч…» (отчёт в `research/<тема>/`).

- Как устроено: `{пакет}/docs/how-it-works.md`; безопасность простыми словами: `{пакет}/docs/security.md`.

## Обновление («обнови search-kit»)
1. `git -C "{пакет}" pull`; показать, что нового: `git -C "{пакет}" log --oneline -10`.
2. Тот же установщик, что при установке (`tools/install.py bb | claude | <папка>`): он обновит ярлыки или плагин.

## Удаление («удали search-kit»)
С «да»: BB и другие оболочки: убрать ярлыки скилов пакета из папки скилов оболочки; Claude Code:
`claude plugin uninstall search-kit@search-kit-marketplace`. Папку пакета и `my/` (там ключи) человек удаляет сам,
если хочет; напомнить, что ключи можно отозвать в кабинетах сервисов.
