# BB и другие агенты (Codex, Gemini CLI, Antigravity и т. п.): что особенного

## Как BB устроен (сказать человеку коротко)
- **Скилы общие для всех агентов.** BB сам подставляет скилы из `~/.bb/skills` в любой тред: Claude Code, Codex, Pi,
  агенты из реестра ACP (`bb acp registry`: Gemini CLI, Antigravity и другие). Поставили один раз: видят все,
  в том числе новый агент. Установщик кладёт в `~/.bb/skills` ярлыки на папку пакета; BB работает с их копией,
  поэтому в скилах есть `kit-home.txt` с адресом пакета: по нему скрипты находят `my/`.
- **Подключения (MCP) у каждого агента свои.** Общего списка, который BB раздаёт агентам, нет. Плагин
  `mcp-manager` (по желанию: `bb plugin install git:https://github.com/sankalpaacharya/bb-mcp-manager.git`)
  показывает подключения всех агентов одним списком, переподключает и удаляет, но не переносит в другого агента.
- **Охранник пакета работает только как хук Claude Code** (плагин). В BB его нет: файл ключей защищают правила
  скилов (агент его не открывает и не выводит) и то, что ключи человек вписывает сам, формой BB или в редакторе.

## Подключения поиска (обязательно): для каждого агента
Сначала посмотреть, что уже есть (`bb mcp-manager list`, если плагин стоит, или команда списка самого агента).
Есть под именами `keenable`, `tavily`, `firecrawl`: не дублировать.
- **Claude Code в BB:** те же команды, что в `references/claude-code.md`, раздел «Подключения поиска».
- **Codex:** Keenable без ключа: в `~/.codex/config.toml` раздел `[mcp_servers.keenable]` с
  `url = "https://api.keenable.ai/mcp"`. Tavily и Firecrawl с ключом: раздел `[mcp_servers.tavily]`,
  `url = "https://mcp.tavily.com/mcp/"`, `bearer_token_env_var = "TAVILY_API_KEY"`; ключ Codex берёт из переменной
  среды. Её человек задаёт сам, не в чате: Windows: Пуск → «Изменение переменных среды текущего пользователя» →
  Создать; Mac и Linux: строка `export TAVILY_API_KEY=...` в `~/.zshrc` или `~/.bashrc`. Затем перезапустить BB.
- **Gemini CLI, Antigravity и другие агенты ACP:** по инструкции к MCP этого агента; ключ так же через переменную
  среды. Keenable без ключа: адрес `https://api.keenable.ai/mcp`.
- Человек хочет подключить сам через интерфейс BB или агента: дать адреса выше и проверить в новом треде.
- Проверка в новом треде этого агента: по одному пробному вызову каждого (поиск одного слова). 401: ключ неверный.

## Помощники для deep-research
Именованные помощники `search-kit:researcher` и `search-kit:social-researcher` есть только в плагине Claude Code.
В BB deep-research запускает обычного помощника и вставляет правила из `deep-research/agents/` в его задание:
ставить ничего не нужно.

## Обновление
`git -C "{пакет}" pull`, затем `python -I "{пакет}/tools/install.py" bb` (ярлыки уже стоят, обновление видно сразу;
скрипт проверит адреса и `my/`), новый тред.
