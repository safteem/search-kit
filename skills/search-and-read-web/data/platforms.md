# Рецепты крупных площадок (строка на площадку; дата проверки)

| Площадка | Как открыть и искать | Ловушки |
|---|---|---|
| Google Hotels | встроенный браузер, `google.com/travel/hotels`, даты и гости в форме, валюта в настройках (USD) | «Nightly total» уже с налогами; койки и комнаты в квартирах не показывает (25.11.2026) |
| Booking | встроенный браузер, фильтры в адресе (`checkin`, `checkout`, `group_adults`, `selected_currency=USD`) | сумма за срок, налоги отдельной строкой; координаты в `data-atlas-latlng`; Genius-цены только после входа (25.11.2026) |
| Agoda | встроенный браузер, переход из Google Hotels даёт особую цену | в выдаче цена за ночь без налогов; итог виден только на оформлении (25.11.2026) |
| adidas.com/us | встроенный браузер; выдача `/us/<slug>` (`men-black_friday-shoes` и т. п.); во вкладке JSON: `/api/plp/content-engine?query=<slug>&start=N`, `/api/products/<id>`, `/api/products/<id>/availability`, `/api/models/<modelId>/reviews` | Akamai блокирует после ~200 быстрых запросов (403 + капча); 83 последовательных с паузой 1,5 с прошли без блока; `availableSizes` в выдаче врёт; свободный текст в `query` не работает, `&sort=price-low-to-high` работает; совет по размеру — `attribute_list.size_fit_bar.selectedMarkerIndex` (обувь: 5 делений, 0 маломерит, 2 в размер, 4 большемерит; одежда: 3 деления, 1 в размер, 2 большемерит — смотреть `markerCount`); отзывы — с параметрами `includeLocales=en*` и `bazaarVoiceLocale=en_US`, иначе 500, пусто или «Invalid Locale»; в `product_link_list` другие цвета модели — записи типа `color-variation` (остальное — «complete the look»); поиск свободным текстом — `/api/search/query?query=<текст>`; остатки API показывает до 15 пар; Firecrawl только на публичную карточку. adidas.co.uk и .de закрывают браузер сразу, доставка только внутри страны домена (25.11.2026) |
| aversi.ge | Cloudflare: встроенный браузер или Firecrawl открывают, agent-browser нет | наличие в аптеках города смотреть отдельно от онлайн-магазина (24.11.2026) |
