# Карты (Google, по просьбе Яндекс): поиск, сводка, отбор, отзывы

Читать, когда в вопросе есть место, заведение, компания, мастер или специалист с адресом («куда сходить», «где
поесть», «найди клинику», «проверь по отзывам на картах»), локационный критерий («рядом с метро», «до центра пешком»)
или список компаний (лиды). Яндекс Карты — только по просьбе (СНГ).
Скрипты: `apify.py` = `python -I {скилы}/social-capture/scripts/apify.py`, сводка =
`python -I {скилы}/search-and-read-web/scripts/maps.py`. Выдачи — в файлы во временной папке сессии,
в разговор только сводка. В запросах никаких личных данных (имена клиентов, адреса людей): они уходят в Apify.

## Два режима
- **Выбор** (куда сходить, к кому пойти, какую клинику выбрать): шаги 1–9 ниже, итог — свой рейтинг из 3–5 мест.
- **Список** (лиды, «найди 10 компаний с рейтингом 4+ без сайта»): только шаги 1–2 с фильтрами и `--sort count`
  (больше отзывов — живой бизнес); отзывы не брать, если не просят.

## Шаг 1. Сбор мест — Apify `kaix/google-maps-places-scraper` ($0,00008 за место)
`apify.py run kaix/google-maps-places-scraper <вход.json> <выход.json> 0.1` (10–100 секунд).
```json
{"searchTerms": ["burger", "бургерная", "ბურგერი"], "location": "Tbilisi, Georgia", "searchType": "area",
 "radius": 8, "radiusUnit": "km", "maxResults": 60, "skipClosedPlaces": true, "language": "ru"}
```
- 2–3 формулировки: язык страны и английский, как назвал бы место владелец. `maxResults` — потолок на весь запуск,
  ставить всегда (без него Тбилиси дал 737 мест за $0,11 с мусором вроде стоматологий и турфирм).
- `searchType: "area"` — сетка по области, находит глубже (сантехники Ричмонда без сайта: area 97 мест, nearby 2).
  Компании без адреса (работают по выезду) area тоже отдаёт.
- Фильтры: `minRating` (2.0–4.5), `websiteFilter` (`withoutWebsite` для лидов), `categoryFilters` — слова, место
  проходит, если подходит **любая** его категория (у бизнеса их несколько: home care и home health care, косметолог
  и салон красоты); список слов широкий, на языке выдачи. Граница города вместо радиуса — `city`, `state`, `country`.
- Места, которые советуют люди (Threads, Telegram, Instagram), — в тот же запуск через `companies`
  (`[{"name": "...", "city": "Tbilisi", "country": "Georgia"}]`: город и страну указывать всегда, иначе находится
  одноимённое место в другой стране) или `placeIds`. Если в выдаче оказались только места из `companies`, поиск
  по словам не выполнился (замечено 26.11.2026): `companies` запускать отдельным запуском.
- Локационный критерий «рядом X» (метро, парк, спортзал): отдельный запуск той же области по X, `maxResults` 30–60,
  файл — в `--near` сводки. Выдачу ориентиров перед сводкой почистить (в «метро» попадают автовокзал, фуникулёр, магазин
  METRO): `categoryFilters` (`subway`, `metro station`, `станция метро`) и глазами.
- Известные места поиск по словам может пропустить (тест «хинкали»: Kutkhe, Дафна) — добирать через `companies`.

## Шаг 2. Сводка 1: таблица мест
`maps.py places <сводка.md> <места.json> [ещё.json] [--center "ШИР,ДОЛ::название"] [--near "<X.json>::метро"] [--min 10] [--sort count]`
- Порядок: рейтинг, при равенстве до 0,1 выше тот, у кого больше отзывов. Места с малым числом отзывов (меньше
  `--min`, по умолчанию 10) **не отсекаются**: отдельный блок ниже основной таблицы.
- Столбцы: рейтинг, число отзывов, категории, район, сайт, часы (24/7 или будни/сб/вс: для срочных вопросов это фильтр), «рядом» (Google — ближайший ориентир с расстоянием,
  Яндекс — ближайшее метро), расстояния до точки и до ближайшего X — по прямой, ≈ минуты пешком (×1,3 на улицы).
- Приблизительного расстояния хватает. Точный маршрут — только по просьбе или в отдельном кейсе (шаг 8а).
Сводку прочитать целиком.

## Шаг 3. Отбор (модель)
- **Сначала тема, потом цифры:** отсечь не по теме (бар с бургером в меню, сеть, если ищем авторское).
- Короткий список 6–8 мест: лучшие по рейтингу и числу отзывов + все, кого советуют люди + 1–2 места с высокой
  оценкой и малым числом отзывов («мало отзывов» — не минус: хороший специалист может быть почти без отзывов;
  такие места читать целиком, их отзывов немного).
- Локационный критерий, который поставил пользователь, — обязательный фильтр; не проходит по прямой — вниз с пометкой.
- Срочный вопрос («сегодня ночью», «сейчас»): часы — обязательный фильтр, круглосуточные вперёд.
- Цены — только если бюджет в критериях; иначе во второй круг по топу (сайт, Instagram, цены в отзывах).
  У ресторанов в выдаче бывает `priceRange`, у услуг почти никогда.

## Шаг 4. Отзывы короткого списка — Apify `kaix/google-maps-reviews-scraper` ($0,00004 за отзыв)
Два запуска на весь список (места — `placeId` из блока внизу сводки `maps.py places`: взять id только короткого
списка; места из колонки «Рядом» — соседи, их не брать):
- свежие: `{"urls": ["<placeId>", ...], "maxReviews": 25, "sort": "newest", "language": "ru"}`;
- худшие: то же с `"maxReviews": 15, "sort": "lowest"`.
`language` — язык, на который Google переводит отзывы (для ответа по-русски — `ru`). `searchQuery` — только отзывы
со словом (критерий из вопроса: «навяз», «portion»). ~$0,002 на место.

## Шаг 5. Сводка 2: срезы отзывов
`maps.py reviews <срезы.md> <свежие.json>::fresh <худшие.json>::low --places <места.json>[,ещё.json] [--grep "навяз|upsell"]`
(файлы мест — все, откуда пришли места короткого списка, через запятую; иначе у части мест не будет общей оценки)
По каждому месту: общая оценка против средней свежего среза, звёзды среза, разброс дат и всплеск (больше всего
отзывов за 3 дня), худшие (≤3★) с датой и ответом владельца, свежие коротко, строки с `--grep`. Прочитать целиком.

## Шаг 6. Разбор (модель), по каждому месту
- **Критерий из вопроса:** косметолог — «навязывают»; бургерная — порции, цена, ожидание. Ищется в текстах.
  «Не для туристов», «где едят местные» — доля языков среди отзывов с текстом (строка в сводке: язык страны против
  английского и прочих) плюс прямые слова в отзывах (tourist, туристы).
- **Худшие:** повторяется ли жалоба и свежая ли она, или разовый случай двухлетней давности. Ответ владельца
  показывает, как место разбирается с жалобами (извинились и исправили, огрызнулись, молчат).
- **Тренд:** свежий срез хуже общей оценки на 0,5 и больше — значимо (место испортилось); 0,3–0,4 — «возможно»;
  меньше — разброс. Срез меньше 15 отзывов — тренд не оценивать.
- **Сбор отзывов** (всплеск, одно имя сотрудника в десятке отзывов, короткие одинаковые тексты) — нейтральная пометка
  «у места есть процесс сбора отзывов». Это не обман и не минус: свежий срез тогда меньше говорит о качестве,
  опора — на худшие и более старые отзывы. Бьюти-ниша (Тбилиси, 11.2026): средний рейтинг 4,76, десятки мест с 5,0 —
  там звёзды мало различают, решают срез и люди.

## Шаг 7. Сверка с людьми
Найдено на картах и советуют в соцсетях или чатах (или наоборот, неважно, где нашли первым) — место поднимается.
Расходится (люди советуют, а на картах плохо, или на картах хорошо, а люди не рекомендуют) — пометить «расходится»,
сказать, в чём именно, и опустить. Хорошие карты без упоминаний людей — «неизвестно», а не «плохо».

## Шаг 8. Углубление
- Топ-2–3 после шагов 6–7: по 100 свежих отзывов (`maxReviews: 100`, метка `::deep`, ~$0,004 на место).
- **8а. Точное время в пути** — по просьбе или когда критерий жёсткий: Firecrawl Maps `businesses/directions`
  (`alexandria_library_read`, provider `firecrawl-maps`; `origin`, `destination` — адрес, название или «шир,дол»;
  `mode`: walking, transit, driving, bicycling; `country`), 5 кредитов за маршрут, только для короткого списка.
  Проверено: Тбилиси пешком, 2,5 км — 37 минут.

## Шаг 9. Итог
Рейтинг из 3–5 мест. У каждого: оценка и число отзывов, ссылка на карту, почему место в списке (главный плюс, тренд,
совпадение с людьми), главная жалоба из худших, пометки «мало отзывов», «расходится», «есть процесс сбора отзывов».

## Яндекс Карты (по просьбе) — Apify `dami_studio/yandex-maps-scraper`
$0,0004 за место, $0,0003 за отзыв, ~30 секунд. Логика та же (шаги 1–9), сводка та же (`maps.py` понимает поля Яндекса).
```json
{"searchQueries": ["косметолог"], "city": "Тбилиси", "maxItems": 40, "reviewsPerPlace": 25, "language": "ru_RU"}
```
- Отдаёт рейтинг, число оценок, ближайшее метро и остановки с расстоянием, отзывы внутри места (до 50).
- Фильтр `minReviews` при редкой категории останавливает поиск («FILTER_TOO_RARE», 7 из 63): не ставить, отсекать в сводке.
- Порядок отзывов Яндекса не «свежие»: тренд по нему не оценивать. В Тбилиси покрытие Яндекса небольшое.

## Запасные пути (только когда Apify отказал в запуске)
- **Firecrawl Maps** (`alexandria_library_read`, provider `firecrawl-maps`): `businesses/search` — 20 мест за вызов
  (рейтинг, число отзывов, телефон, сайт; `cursor` для следующих 20), `businesses/reviews` — до 60 отзывов
  (`feature_id` из поиска, `sort`: newest, lowest), 10 кредитов за вызов. Ответ целиком приходит в разговор
  (15–25 тыс. токенов): брать мало страниц. Фильтров «без сайта» и «рейтинг от» нет.
- `compass/crawler-google-places` и `compass/Google-Maps-Reviews-Scraper` — те же данные в 15–50 раз дороже, минимальный
  потолок запуска $0,50, с фильтрами мельче (Ричмонд без сайта: 3 места против 97 у kaix).
- Google Places API не используем: нужна карта в Google Cloud, отзывов не больше 5.
