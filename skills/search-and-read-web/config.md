# Настройки поиска по умолчанию

Общие для всех. Личные значения — в `my/my-config.md` (`my/` — личная папка пакета; где она лежит, печатает `python -I "{скилы}/social-capture/scripts/keys.py" where`) (те же разделы): прочитай его после этого файла,
личное значение побеждает. Нет личного файла — работай по этому и в конце первого ответа предложи настройку
(скил `search-kit-setup`). Поменять лимит или язык можно, просто сказав об этом своему агенту: он поправит личный файл.

## Пользователь
- Язык ответов: язык, на котором пишет пользователь.
- Страна и город: не заданы (тогда местная тема — страна из вопроса).
- Языки поиска: по умолчанию английский (на нём больше всего материалов); местная тема — сначала язык страны,
  потом английский. Язык общения не делает его языком поиска.

## Бюджет
Пакет рассчитан на бесплатные тарифы: Keenable, Tavily, Firecrawl, Apify ($5 в месяц), Groq. Платить со временем
придётся только ScrapeCreators (пополнение кредитов).
- Потолка на ответ нет: тратить столько, сколько нужно вопросу, и **всегда** показывать строку «Расход».
- Apify: запуск до **0,5 долл.** без вопроса; лимит передавать последним аргументом `apify.py run ... 0.5` или меньше.
  Дороже — назвать цену и спросить. `apify.py run` после запуска печатает потраченное за месяц: с $4 — сказать
  пользователю в «Расходе». Сверх бесплатного кредита Apify не списывает, а отказывает в запуске: запасные пути —
  только когда запуск не прошёл.
- С вопросом и ценой: `tavily_research`, обходы сайтов, `firecrawl_agent`, платные форматы Firecrawl.

## Предпочтения при выборе
Не заданы. Когда пользователь выбирает (место, мастер, товар, сервис) — критерии из отзывов и обзоров плюс то, что
он сам говорил о себе в личном файле; неясно важное — спросить одним вопросом.

## Браузер агента
- Встроенный браузер оболочки: в приложении Claude — `mcp__Claude_Browser__*`; в BB — `bb browser-automation`,
  на Windows режим desktop (headless только на Linux и Mac). Подробно — `references/platforms.md`, пункт 5.
- Запасной: agent-browser (по желанию), профиль браузера — в личном файле. Входы только в аккаунты агента.
