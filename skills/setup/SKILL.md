# Установка и обучалка search-kit

Ведёшь человека по шагам, по-человечески, без жаргона: что делаем, зачем, сколько стоит. Каждый шаг: проверка,
что уже есть, и только недостающее. Ничего не ставишь и не меняешь без «да». Ключи человек вписывает сам: ты их
не видишь, не просишь прислать в чат и не выводишь. Прислал ключ в чат: не ругать: помочь перенести в файл ключей
и предложить выпустить новый ключ в кабинете сервиса.

`{скилы}`: папка со скилами пакета (на уровень выше папки этого скила). Команды: `python -I "<полный путь>/..."`
(на Mac и Linux `python3`), прямые косые, путь в кавычках.

## Шаг 0. Где ставим
Определить оболочку: есть переменная окружения `BB_THREAD_ID` или команда `bb`: BB; иначе, если это Claude Code
(плагин `search-kit` в списке скилов): Claude Code; иначе спросить человека, в какой программе он работает.
Сказать человеку, какой путь выбран.

## Шаг 1. Что в пакете (рассказать коротко)
- **search-and-read-web**: главный: любой вопрос, где нужны свежие факты, опыт людей, отзывы, цены. Сам выбирает
  площадки по признакам вопроса (Google и Keenable всегда; YouTube, Reddit, X, Threads, карты, магазины, GitHub: по
  смыслу) и приносит ответ со ссылками и строкой «Расход».
- **social-capture**: разбор конкретного поста по ссылке: текст, цифры, расшифровка речи, комментарии, кадры.
- **deep-research**: большой ресерч: несколько помощников ищут параллельно кругами, пока ответ не станет глубоким,
  критик проверяет отчёт.
- **telegram-search**: по желанию: поиск по своим Telegram-чатам и каналам.
- **setup**: этот скил.
Сколько стоит: всё на бесплатных тарифах; со временем пополнять придётся только ScrapeCreators. Лимиты можно поменять,
просто сказав об этом.

## Шаг 2. Программы
Проверить: `python --version` (нужен 3.10+; на Mac и Linux `python3`), `ffmpeg -version`, `git --version`.
Нет чего-то: предложить установку (с вопросом). Windows: `winget install Python.Python.3.13`, `winget install Gyan.FFmpeg`,
`winget install Git.Git`; Mac: `brew install python ffmpeg git`; Linux: пакетный менеджер. ffmpeg нужен только
для кадров из видео, без него остальное работает.

## Шаг 3. Ключи и шаг 4. Подключения поиска: по пути своей оболочки
Ключи и подключения в Claude Code и в BB ставятся по-разному. Прочитать только свой файл и пройти по нему:
- Claude Code без BB: `references/claude-code.md` (ключи в файле, который человек заполняет сам в Блокноте);
- BB: `references/bb.md` (ключи через форму хранилища секретов BB, подключения отдельно для каждого агента);
- другая оболочка (Codex, OpenCode и т. п.): `references/bb.md`, разделы «Установка скилов» (папка скилов этой
  оболочки), «Ключи» (вместо формы BB: файл, как в `references/claude-code.md`) и «Подключения поиска» (пункты Codex и агенты ACP).
Где взять ключи (сказать в начале, у каждого есть бесплатный вход; размер бесплатного тарифа уточнить на странице
сервиса в момент настройки, цифры меняются): ScrapeCreators: scrapecreators.com (Google, YouTube, Reddit, соцсети);
Apify: apify.com (X, ответы Threads, карты; бесплатно $5 в месяц); Groq: console.groq.com (расшифровка речи);
Tavily: tavily.com; Firecrawl: firecrawl.dev. Keenable (keenable.ai) работает и без ключа, с лимитом. Предложить
поискать промокоды и бонусы при регистрации (скил поиска, `references/promo-codes.md`).
Ключ в чат не просить и не выводить. Прислал в чат: не ругать, помочь перенести и предложить выпустить новый.

## Шаг 5. Личный файл
Задать вопросы по одному и записать ответы в `~/.search-kit/my-config.md` (разделы как в
`{скилы}/search-and-read-web/config.md`, только то, что отличается): имя (по желанию), страна и город, языки
ответов и поиска, своя работа или интересы (откуда брать источники), лимиты трат (по умолчанию Apify до $0,5 за запуск
без вопроса), предпочтения при выборе (бюджет, что важно). Показать файл и записать после «да».

## Шаг 6. Telegram (по желанию)
Спросить, нужен ли. Нет: пропустить: без Telegram всё остальное работает.
- По умолчанию пакет рассчитан на **второй аккаунт Telegram**, а не основной: так агент читает только те чаты, куда
  этот аккаунт вступил, и личная переписка ему не видна. Есть второй аккаунт: подключаем его; нет: можно завести
  или подключить основной на своё усмотрение (тогда агент видит все его чаты).
- Нужен `uv` (менеджер Python-окружений): `uv --version`; нет: Windows `winget install astral-sh.uv`, Mac
  `brew install uv`.
- Сервер: открытый `telegram-mcp` (github.com/chigwell/telegram-mcp): `git clone` в любую папку, `uv sync`,
  вход по его инструкции (API ID и hash с my.telegram.org вписывает человек сам). Скрипт поиска вызывает только
  инструменты чтения.
- Записать `~/.search-kit/telegram.json`:
  `{"python": "<папка telegram-mcp>/.venv/Scripts/python.exe", "server": {"command": "uv", "args": ["--directory", "<папка telegram-mcp>", "run", "main.py"]}}`
  (на Mac и Linux python: `.venv/bin/python`). Уже есть свой способ запуска сервера: вписать его в `server`.
- Карту чатов построить по разделу «Карта чатов: как построить» скила `telegram-search` и показать человеку.
- Проверка: `python -I "{скилы}/telegram-search/scripts/tg_search.py" global <временная папка> --q "<слово>"`.

## Шаг 7. Браузер
Для магазинов, отелей и площадок с фильтрами нужен браузер агента: встроенный браузер оболочки (в приложении Claude :
браузерная панель, в BB: его браузер). Проверить, что он есть. Запасной: agent-browser (по желанию, отдельный профиль,
входы только в запасные аккаунты); путь к профилю: в личный файл.

## Шаг 8. Пробные запросы
Сделать 2–3 запроса из разных сценариев и по ходу объяснять, что происходит: какие признаки увидел, какие площадки
выбрал и почему, сколько потратил. Например: один простой факт (только база), один «опыт людей» (Reddit или Threads),
один «место с адресом» (карты). Запросы: про то, что интересно человеку (из шага 5). В конце: строка «Расход»
и где поменять настройки.

## Обучалка: как пользоваться
- Просто спрашивать своими словами: «найди…», «что пишут про…», «какой лучше…», «посмотри в Reddit…». Назвал
  площадку: агент пойдёт туда обязательно.
- Ссылка на пост: «разбери этот пост»: social-capture.
- Большая тема: «сделай глубокий ресерч…»: отчёт в папке `research/<тема>/`.
- В каждом ответе строка «Расход»: по ней видно, что сколько стоит, и можно попросить потолок.
- Что внутри и почему так: `docs/how-it-works.md` в репозитории пакета; безопасность простыми словами :
  `docs/security.md`; пример прогона «задаёшь запрос: вот что происходит»: `docs/tutorial.md`.

## Обновление
По файлу своей оболочки, раздел «Обновление». Личный файл и ключи лежат вне пакета, обновление их не трогает.
