# search-kit

Набор скилов, который учит ИИ-агента искать как хороший живой ассистент: сам выбирает, где искать, читает
источники самым дешёвым рабочим способом и приносит готовый ответ со ссылками и строкой «Расход» (сколько чего
потрачено). Работает в Claude Code, в BB и в других оболочках, которые понимают скилы (папки со SKILL.md).

## Что внутри

| Скил | Что делает |
|---|---|
| `search-and-read-web` | Главный. Любой вопрос, где нужны свежие факты, опыт людей, отзывы, цены, выбор. Google и Keenable всегда; YouTube, Reddit, X, Threads, Instagram, карты, магазины, GitHub, научные статьи подключаются по смыслу вопроса. |
| `social-capture` | Разбор поста по ссылке: текст, цифры, расшифровка речи, комментарии с ответами, кадры из видео. |
| `deep-research` | Большой ресерч: помощники ищут параллельно, кругами, пока ответ не станет глубоким; критик проверяет отчёт и может отправить на ещё один круг. |
| `telegram-search` | По желанию: поиск по своим Telegram-чатам и каналам (второй аккаунт). |
| `search-kit-setup` | Знакомство, установка, ключи, личные настройки, пробные запросы, обновление. |

Плюс два помощника для глубокого ресерча (`researcher`, `social-researcher`) и охранник (`hooks/guard.py`), который
не даёт читать файл ключей и держит помощников в рамках. Подробнее: [как и почему так устроено](docs/how-it-works.md),
[что происходит, когда задаёшь вопрос](docs/tutorial.md), [безопасность простыми словами](docs/security.md).

## Сколько стоит

Всё рассчитано на бесплатные тарифы: Keenable, Tavily, Firecrawl, Apify ($5 в месяц), Groq. Со временем пополнять
придётся только ScrapeCreators (Google, Reddit, YouTube, Threads через него). Лимиты меняются одной фразой агенту.

## Установка

Одинаково для BB, Claude Code, Codex и других агентов, на Windows, Mac и Linux. Скажите своему агенту:

> Установи search-kit: <ссылка на этот репозиторий>. Прочитай README и сделай раздел «Установка (для агента)».

Агент склонирует пакет, поставит его в вашу оболочку и проведёт по настройке: расскажет, что пакет умеет,
какие сервисы нужны и зачем, поможет внести ключи (не видя их) и сделает пробные запросы. Около 15 минут.

### Установка (для агента)
1. Спроси человека, где держать папку пакета (его рабочая папка для агентов, иначе домашняя) и склонируй:
   `git clone <ссылка на этот репозиторий, которую дал человек> "<папка>/search-kit"`.
   Скачивать только командой `git clone`: закрытый репозиторий через веб-страницу или API без входа отвечает 404,
   а git использует вход в GitHub, который уже есть на компьютере. Папка уже есть и пустая: клонировать в неё.
2. Прочитай `skills/search-kit-setup/SKILL.md` в склонированной папке и иди по нему с шага 0. Установка в оболочку
   там — шаг 3 (`python -I tools/install.py bb | claude | <папка скилов>`, сначала с `--dry-run`).

## Нужно на компьютере

Python 3.10+, git; ffmpeg по желанию (кадры из видео). Скрипты пакета используют только стандартную библиотеку Python.

## Где что лежит: всё в одной папке

```
search-kit/            ← папка пакета (копия репозитория); обновление: git pull
├── skills/            ← скилы; оболочка видит их через ярлыки (или плагин в Claude Code)
├── my.example/        ← образец личной папки (на GitHub)
└── my/                ← всё ваше: настройки, ключи, карта Telegram-чатов, резервные копии; в git не попадает
```

- Ключи ищутся так: переменная среды → файл ключей в `my/` → ваш общий файл ключей на все сервисы, если вы его
  указали (`python -I tools/install.py keys-file <путь>`). Уже настроенные ключи вводить заново не нужно.
- Перенос на другой компьютер или сервер: скопировать (или синхронизировать) папку пакета вместе с `my/`
  и запустить установщик для своей оболочки.
- Где сейчас ваша `my/` и файлы ключей: `python -I skills/social-capture/scripts/keys.py where`.

## Обновление

Скажите агенту «обнови search-kit»: он сделает `git pull`, запустит установщик и спросит только про новое
(новые поля настроек, новые ключи). Ваша `my/` при обновлении не меняется.

## Для автора: перед каждым пушем

`python -I tools/check_before_push.py`: ищет в пакете ключи, личные пути и имена. Пуш только при пустом результате.
Подключить как git-хук: `git config core.hooksPath tools/git-hooks`.
