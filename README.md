# search-kit

Набор скилов, который учит ИИ-агента искать как хороший живой ассистент: сам выбирает, где искать, читает
источники самым дешёвым рабочим способом и приносит готовый ответ со ссылками и строкой «Расход» (сколько чего
потрачено). Работает в Claude Code, в BB и в других оболочках, которые понимают скилы (папки со SKILL.md).

## Что внутри

| Скил | Что делает |
|---|---|
| `search-and-read-web` | Главный. Любой вопрос, где нужны свежие факты, опыт людей, отзывы, цены, выбор. Google и Keenable всегда; YouTube, Reddit, X, Threads, Instagram, карты, магазины, GitHub, научные статьи подключаются по смыслу вопроса. |
| `social-capture` | Разбор поста по ссылке: текст, цифры, расшифровка речи, комментарии с ответами, кадры из видео. |
| `deep-research` | Большой ресерч: помощники ищут параллельно, кругами, пока ответ не станет глубоким; критик проверяет отчёт и может отправить на ещё один круг. |
| `telegram-search` | По желанию: поиск по своим Telegram-чатам и каналам (второй аккаунт). |
| `setup` | Установка, настройка ключей, личный файл, пробные запросы, обучалка. |

Плюс два помощника для глубокого ресерча (`researcher`, `social-researcher`) и охранник (`hooks/guard.py`), который
не даёт читать файл ключей и держит помощников в рамках. Подробнее: [как и почему так устроено](docs/how-it-works.md),
[что происходит, когда задаёшь вопрос](docs/tutorial.md), [безопасность простыми словами](docs/security.md).

## Сколько стоит

Всё рассчитано на бесплатные тарифы: Keenable, Tavily, Firecrawl, Apify ($5 в месяц), Groq. Со временем пополнять
придётся только ScrapeCreators (Google, Reddit, YouTube, Threads через него). Лимиты меняются одной фразой агенту.

## Установка

**Claude Code.** Скажите своему Claude:

> Установи плагин search-kit из https://github.com/<владелец>/search-kit и запусти его скил setup.

Или сами, в терминале:

```
claude plugin marketplace add <владелец>/search-kit
claude plugin install search-kit@search-kit-marketplace
```

Потом в новой сессии: «настрой search-kit».

**BB (getbb.app).** Скилы в BB общие для всех агентов (Claude Code, Codex, Pi, Gemini, Antigravity и других), поэтому
пакет ставится в BB, а не в настройки одного агента. Скажите агенту в BB:

> Склонируй https://github.com/<владелец>/search-kit, поставь скилы командой `python -I tools/install.py ~/.bb/skills` и запусти скил setup.

Установщик кладёт каждый скил своей папкой в `~/.bb/skills` (если это ярлык на вашу папку скилов, то туда), чужие скилы
не трогает, старые версии своих убирает в `~/.search-kit/backups/`. Ключи setup спросит формой хранилища секретов BB.

**Другие оболочки** (Codex, OpenCode, свои агенты): так же `install.py` в папку скилов оболочки. Охранник
подключается хуком оболочки, если она их умеет: у Codex формат хуков тот же, запись в `~/.codex/hooks.json` с полным
путём к `hooks/guard.py` (подробно в [безопасности](docs/security.md)).

В каждой оболочке скил `setup` проверит Python, ffmpeg и git, подскажет, где зарегистрироваться, проверит ключи
(не показывая их), подключит недостающие сервисы, задаст пару вопросов для личного файла и сделает пробные запросы.

## Нужно на компьютере

Python 3.10+, git; ffmpeg по желанию (кадры из видео). Скрипты пакета используют только стандартную библиотеку Python.

## Где лежит личное

Пакет одинаковый у всех. Своё лежит вне его, обновления это не трогают:
- `~/.search-kit/my-config.md`: имя, страна, языки, лимиты, предпочтения;
- `~/.search-kit/telegram.json`, `~/.search-kit/telegram-chats.md`: Telegram, если подключён;
- ключи: `~/.search-kit/credentials.md` (Claude Code; заполняете сами в Блокноте) или `~/.search-kit/.env` (BB: его пишет
  форма секретов BB). Старое место `~/.claude/credentials.md` тоже читается.

## Обновление

Claude Code: скажите «обнови search-kit» (или `claude plugin marketplace update search-kit-marketplace`, затем
`claude plugin update search-kit@search-kit-marketplace`). BB и другие оболочки: `git pull` в папке пакета, затем снова
`python -I tools/install.py <папка скилов>`.

## Для автора: перед каждым пушем

`python -I tools/check_before_push.py`: ищет в пакете ключи, личные пути и имена. Пуш только при пустом результате.
Подключить как git-хук: `git config core.hooksPath tools/git-hooks`.
